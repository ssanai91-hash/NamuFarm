# 묘목 정보·블로그

홈페이지의 `묘목 정보·블로그 보기`, PC 상단의 `묘목 블로그`, 모바일 메뉴에서 별도의 글 목록을 엽니다. 큰 카테고리 버튼, 제목·요약 검색, 작성일, 출처, `블로그에서 읽기`를 제공합니다. 처음 20개를 표시하고 `더 보기`로 20개씩 추가합니다. 네이버 원문은 새 창으로 열리므로 기존 검색·카테고리·스크롤과 견적 입력 상태가 남아 있습니다. 목록을 닫았다가 다시 열어도 조건과 위치를 복원합니다.

## 최초 목록

2026-10-20 `ohappyrich`의 공개 카테고리 목록에서 부모 카테고리 `82`(나무팜-전국묘목유통) 아래 다섯 분류를 확인했습니다. 각 분류의 공개 글 목록을 200개 한도로 읽고 실제 건수를 카테고리 집계와 대조했습니다. 가장 큰 분류도 138개여서 응답 한도를 채운 분류가 없습니다. 중복 없이 총 205개입니다. 별도 개인 일상·칼럼·부동산 카테고리는 수집하지 않습니다. 분류는 원본 블로그의 분류를 유지하며 글의 주제로 재분류하지 않습니다.

| categoryNo | 홈페이지 표시 | 원본 분류 | 글 수 |
| --- | --- | --- | --- |
| 88 | 나무팜 안내 | 나무팜안내(공지) | 1 |
| 61 | 묘목 분양 | 묘목분양 : 전국 도·소매 | 138 |

공개 제목과 작성자가 제공한 `briefContents`를 검토해 짧은 안내용 요약을 작성했습니다. 설명이 거의 없거나 영상만 있는 글은 제목을 근거로 소개하며 내용을 추측하지 않습니다. 본문 전문·사진은 재게시하지 않습니다. 제목은 원본을 유지합니다. 과거 글의 가격·행사·판매 상태를 현재 정보로 해석하지 않도록 작성일과 공통 안내를 표시합니다. 수집 경로와 글 ID는 `docs/blog-catalog-20261020.json`에 기록했습니다.

## 추가·수정·삭제

`lib/blog-catalog.json`의 `items`에 아래 형식으로 추가합니다. 기존 항목의 요약·제목·분류를 수정하거나 항목을 삭제할 수도 있습니다. 수정 후 `updatedAt`을 실제 확인일로 바꾸고 테스트·배포합니다.

```json
{
  "title": "원본 글 제목",
  "summary": "원문 내용을 확인하고 직접 정리한 짧은 요약",
  "categoryNo": 85,
  "url": "https://m.blog.naver.com/ohappyrich/224237345320",
  "publishedAt": "2026-04-10"
}
```

위 날짜는 형식 설명용 예시입니다. 실제 등록 시 원문의 작성일을 사용합니다. 제목 200자·요약 240자 이내이며 다섯 분류의 번호만 허용합니다. 주소는 지정한 블로그의 개별 글 HTTPS 주소만 사용하고 추적 쿼리를 제거합니다. 같은 글을 중복 등록해도 한 번만 표시합니다. 화면은 최신 작성일 순으로 정렬합니다.

이 목록은 확인 시점의 스냅샷입니다. 새 글·수정·비공개·삭제를 자동 추적하지 않습니다. RSS는 최신 50개만 반환하며 확인 당시 다른 카테고리의 글도 포함했으므로 전체 동기화의 대체 자료로 사용하지 않았습니다. 향후 자동 갱신을 추가할 때는 분류·공개 상태·삭제 반영까지 함께 설계해야 합니다.

기존 영상 자료실·운영 Google Sheets·Apps Script·견적 API·도메인·환경 변수는 변경하지 않습니다. 블로그 데이터는 영상 API와 별개이므로 영상 목록 갱신 실패와 관계없이 열립니다.
