# 초기 앱에 견적 모드 추가

개발 브랜치: restore/android-initial-20260927.

- 상단 탭/좌우 이동: 견적 → 문의처리 → 매매 → 농원·묘목.
- 첫 화면은 견적 모드. 매매·관리 화면 및 기존 리소스는 초기 커밋의 원문 그대로 유지한다.
- 견적 화면은 기존 견적 앱의 목록·입력 화면·발송 확인 워크플로를 재사용한다.
- 운영 서버는 이미 배포된 snapshot_requests / save_quote_pricing / close_request API를 사용한다.
- 농원·묘목 동기화와 동일한 기기 연결 사용. 서버 주소 입력 화면은 추가하지 않는다.

## 견적 처리

1. 가져오기로 신규·확정 견적을 기기에 보관한다.
2. 고객 요청을 선택해 단가와 배송비를 입력한다.
3. 문자·메일 버튼이 휴대폰의 작성 앱에 수신처와 견적 본문을 채운다.
4. 판매자가 실제 발송 후 견적완료에서 발송 방법을 확인한다.
5. 확정 대기 기록을 먼저 저장하고 서버 확인 후에만 확정 목록으로 이동한다.

외부 작성 앱을 연 것만으로 발송 완료로 표시하지 않는다.
확정 응답 유실 시 같은 입력으로 다시 확인할 수 있으며, 자동으로 문자·메일을 다시 보내지 않는다.
확정 목록은 이 기기의 기록과 운영 시트에서 확정된 견적을 중복 없이 표시한다.
다른 기기의 확정 단가·배송비도 서버의 quotePricing을 읽어 조회한다.

## 저장과 보존

기존 NamuFarm.db(농원·묘목·재고·주문)는 변경하지 않는다.
견적 요청 캐시는 NamuFarmQuotes.db에 분리하고, 발송·확정 저널은 quote_workflow_v1에 저장한다.
목록 전체의 페이지·전체 건수·스냅샷 식별자를 검증한 뒤 한 트랜잭션으로 반영한다.
중간 다운로드 실패나 불완전한 응답이면 기존 기기 목록을 유지한다.
읽지 못하는 이전 암호화 요청은 별도로 보관하며 원본 기기 확인 안내를 표시한다.

## 빌드와 확인

applicationId: com.example.namufarm.original, versionCode: 9, versionName: 1.1.6.
기존 초기버전 APK와 같은 서명으로 업데이트한다.
현재는 GitHub Actions를 실행하지 않고 로컬 환경에서 컴파일한다.
기존 UI/리소스·DB 스키마 보존을 확인하고, 배포용 서명키가 없는 환경에서는 시험용 APK로 구분한다.
운영 시트에 시험 견적을 추가하거나 고객에게 시험 문자를 전송하지 않는다.
실기기에서 문자·메일 앱의 발송과 최종 시트 이동 확인은 설치 후 수행한다.

## 공식견적서 (1.1.5)

- 견적 작성창의 각 품목에서 비고 버튼으로 년생·크기·묘목 상태를 입력한다.
- 고객 요청사항과 별도로 판매자 요청사항을 입력한다. PDF의 비고·주요 사항에 반영한다.
- 공식견적서 생성 시 현재 입력을 기기에 먼저 보관하고 PDF·문자용 이미지를 생성한다.
- 견적서 미리보기, PDF 보기·공유, 메일 PDF 및 문자 이미지 작성 앱을 지원한다.
- 발행 스냅샷은 initial_formal_quotes_v1에 저장한다. 같은 견적 내용은 동일 문서번호로 재생성한다.
- 첨부파일은 앱 캐시에 생성하며 FileProvider 읽기 권한으로 전달한다.
- 외부 작성 앱을 연 것만으로 발송·견적확정하지 않는다. 기존 판매자 발송 확인 절차를 유지한다.
- 확정견적 창은 고객·주문 품목·단가·택배비·총금액·요청사항·전송 기록을 구분한다.
- 기존 발송 기록의 식별값은 비고가 비어 있으면 유지한다.

## 고객문의 (1.1.6)

- 견적과 매매 사이 문의처리 탭에서 전 연도 문의를 불러오고 이름·전화·본문으로 검색한다.
- 미처리(open) 기본, 완료(closed)·전체 필터, 원문/답변/이력 팝업을 제공한다.
- 초안은 기기에 먼저 보관하고 명시적으로 서버 저장한다. 문자/메일은 확인창 후 기존 서버에서 발송한다.
- 나피와 같은 문의 API·revision·작업 ID를 사용하며 충돌 시 서버 답변 적용/내 초안 유지를 선택한다.
- 작업 UUID·요청 내용을 통신 전에 저장한다. 결과 불명은 같은 작업의 결과 확인만 하며 자동 재발송하지 않는다.
- 문자 최종 성공/메일 서버 발송 성공 시 완료, 전화 상담 완료·다시 열기는 메모와 이력을 남긴다.
- 독립 DB `NamuFarmInquiries.db`에 목록·초안·작업·커서를 보관한다. 기존 `NamuFarm.db` v13 및 `NamuFarmQuotes.db` v1은 변경하지 않는다.
- 완료 후 30일 만료 자료는 불러오기·기기 목록 로드·기기 내 정리 작업에서 제거한다. 정리 작업은 통신/발송하지 않는다.
- 운영 서버 버전 36을 그대로 사용하며 이번 이식으로 서버를 다시 배포할 필요는 없다.
