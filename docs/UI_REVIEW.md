# 나무팜 UI 정리

## 방향

진한 숲색을 주요 행동과 금액에 사용하고, 따뜻한 밝은 배경과 흰 카드를 기본으로 한다.
수기 견적은 황토색 배지와 텍스트로 구분한다. 빨강은 취소·삭제와 입력 오류에 사용한다.
사진이나 새로운 주문 상태를 추가하지 않는다.

## 화면별 변경

- `ui/SellingHome.kt`: 판매 홈을 상태/콜백 기반으로 분리. 묘목·농원 검색, 전체/초성 탐색,
  오늘 견적·주문 접근, 고정 견적 바구니. 긴 재고 목록은 키가 있는 LazyColumn으로 표시한다.
- `ui/CommerceDialogs.kt`: 견적 작성·오늘 목록·견적 상세·주문 상세를 공통 스타일로 구현.
  고객 정보를 먼저 보여주고, 원본 주문번호는 복사할 수 있다. 주문 상세에 배송주소를 노출하지 않는다.
  긴 품목/규격은 줄바꿈하며, 바구니 품목·배송비·전화번호를 하나의 영역에서 스크롤한다.
  키보드가 열려도 하단 행동 영역과 입력부가 겹치지 않도록 처리한다.
- `ui/components/NamuComponents.kt`: 대화상자, 제목, 빈 화면, 품목 카드, 출처 배지, 배송/금액 표시 공통화.
  `isPrepaid=true, shippingFee=0`은 선불 0원으로 표시한다.
- `ui/SellingModeScreen.kt`: 기존 ViewModel 동작 연결 유지. 실제 재고 수량 선택은 바구니에 담긴 수량을
  제외한 추가 가능 수량을 안내한다. 빠른 견적에서도 수량/단가를 직접 입력한다.
  바구니를 다시 열 때 고객번호와 배송비를 초기화하지 않는다. 관리로 이동해도 바구니를 유지한다.
  기존 배송주소가 있는 주문은 다시 검색하지 않고 받는사람·상세주소·메모를 편집할 수 있다.
- `ui/ManagementModeScreen.kt`: 선택한 농원/묘목 안내, 읽기 쉬운 선택 카드, 수량/가격 직접 입력과
  기존 증감 버튼 병행. 초성은 48dp 이상 가로 스크롤 선택기. 입력 중 뒤로 이동/새 재고 선택 시 확인한다.
- `ui/theme/*`: 색상, 모서리, 금액 타이포그래피 통일.
- `viewmodel/ManagementViewModel.kt`: 견적 저장/주문 확정 진행 상태를 UI에 제공하고, 성공 시에만
  화면 이동 콜백을 메인 스레드에서 실행한다. 직접 숫자 입력의 음수 방어. Room/동기화 규칙은 변경하지 않는다.

## 유지하는 업무 규칙

- Room 저장과 pending transaction, FIFO 전송, Pull 조건은 기존 저장소 계층이 담당한다.
- MANUAL/INVENTORY 구분은 `OrderLineSource`와 기존 summary codec을 사용한다.
- 주문취소는 기존 repository 경로만 호출하며, 이미 취소한 주문의 UI 버튼은 비활성화한다.
- 주문 영구삭제는 제공하지 않는다. 견적 삭제/문자 작성/최근 통화/배송 주소 검색/마스터 관리는 유지한다.
- 검색은 기기 내 재고에만 적용한다. 네트워크 접근이나 데이터 변경은 하지 않는다.

## 검증

`CommerceUiTest`에서 실제 Compose를 Robolectric로 실행해 검색, 추가 가능 수량,
수기 구분, 배송비 0원, 주문 개인정보 표시, 취소 버튼, 빈 목록을 확인한다.
CI artifact `namufarm-ui-review`에 판매·견적·주문 화면의 렌더링 PNG와 테스트 보고서를 보관한다.
샘플 데이터는 테스트 전용이며 실제 DB나 Sheets에 입력하지 않는다.

실폰에서의 키보드, 큰 글꼴, TalkBack, 통화 권한, 외부 문자 앱과 주소 검색 API 동작은 추가 확인이 필요하다.
컴포넌트 터치 영역은 Android 공식 접근성 가이드의 48dp 기준을 적용했다:
https://developer.android.com/develop/ui/compose/accessibility/api-defaults
