# 견적요청 작업대 통합

견적요청 작업대에서 단가 입력, 택배비 선택, PDF 생성·미리보기, 문자·메일 발송을 처리합니다.
하단 **견적 확정**을 누르고 확인해야 서버 상태와 로컬 확정 견적 엑셀이 갱신됩니다.
PDF 생성이나 문자·메일 발송만으로 견적 상태가 바뀌지는 않습니다.

- 선불 택배비는 합계에 포함하며 후불은 별도로 표시합니다.
- 단가·택배비 변경 시 생성했던 PDF를 무효화합니다. 새 PDF를 생성한 뒤 첨부해야 합니다.
- PDF 파일명은 생성 버튼 아래 표시합니다. 메일 발송 시 해당 PDF 첨부 여부를 확인합니다.
- 발송에 사용한 입력은 다시 열 수 있도록 보존하지만, 확정 엑셀에는 자동 등록하지 않습니다.
- 기존 확정견적 화면과 견적전달 창은 유지합니다.

## 서버 배포

요청 상태(`신규`)에서도 문자·메일을 보내려면
`server/quote-requests/SecureCommerce.gs`를 운영 Apps Script에 반영하고
기존 웹앱 배포의 새 버전으로 업데이트해야 합니다.
기존 배포 URL과 시트 설정을 유지합니다.
이 커밋 자체는 운영 서버를 배포하거나 고객에게 메시지를 보내지 않습니다.
