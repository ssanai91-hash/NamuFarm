# Android 견적 전용 흐름

- 홈은 견적요청과 확정견적 두 목록입니다. 판매·입금·배송 작업 화면으로 이동하지 않습니다.
- 견적요청에서 단가·택배비를 정하고 운영 서버의 문자·메일 기능으로 전달합니다. Android에서는 PDF 첨부 없이 본문만 전송합니다.
- 전송만으로 견적확정하지 않습니다. 문자 최종 성공(4000) 또는 메일 완료 응답을 받은 현재 견적만 견적완료할 수 있습니다.
- 단가·택배비·고객 정보 등 견적 내용이 바뀌면 재전송해야 합니다. 미전송 상태에서 완료를 누르면 알림을 표시합니다.
- 문자 접수는 성공으로 보지 않습니다. 결과를 자동 확인하고, 대기가 계속되면 문자 버튼으로 재전송 없이 결과만 재확인합니다.
- 서버의 견적확정 응답을 확인한 뒤 휴대폰에 확정 결과를 저장합니다. 발송완료·입금확인 상태로 추가 진행하지 않습니다.
- 확정견적은 고객·품목·금액·택배비·전송 결과·확정 시각을 확인하고 닫기만 할 수 있습니다.
- 작업 입력과 전송 기록은 앱 전용 로컬 기록에 보존합니다. 서버 확인 또는 최종 로컬 저장에 실패하면 같은 내용으로 완료를 다시 시도할 수 있습니다.
- 기존 Room 자료는 삭제하지 않습니다. 이전에 전송 완료를 기록한 견적은 별도의 이전 저장 견적으로 확인합니다.
- 새 확정 목록은 이 휴대폰에서 완료한 기록을 사용합니다. 다른 기기의 확정견적 통합 가져오기는 포함하지 않습니다.

## 빌드

기존 Android CI에서 `[build apk]`를 포함한 main 커밋은 테스트가 성공한 뒤 기존 영구 서명 설정으로 APK를 만듭니다.
평상시 커밋의 서명 빌드는 실행하지 않습니다. 기존 수동 빌드 입력도 유지합니다.
운영 서버는 신규 요청 상태에서 문자·메일 전송을 지원하는 SecureCommerce.gs 버전이 필요합니다.
이 변경 자체는 실제 메시지를 보내거나 운영 서버를 배포하지 않습니다.
