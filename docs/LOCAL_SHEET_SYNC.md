# PC·안드로이드 간단 연결과 로컬 동기화

두 앱에서 같은 `나무팜-연결.json`을 처음 한 번 선택합니다. 일회용 코드나 별도 복호화 키를 입력할 필요가 없습니다. 기존 기기 연결도 계속 사용할 수 있습니다.

## 서버 적용 (한 번)

1. 기존 Apps Script 프로젝트의 `Code.gs`와 `SecureCommerce.gs`를 이 커밋의 파일로 교체합니다. 나머지 서버 파일과 Script Properties, 시트는 유지합니다.
2. 기존 웹 앱 배포를 새 버전으로 업데이트합니다. PC·안드로이드가 사용하는 `/exec` 주소를 그대로 유지합니다.
3. Apps Script 편집기에서 `createAppConnectionFile`을 한 번 실행합니다. 실행 로그의 Google Drive 링크에서 `나무팜-연결.json`을 내려받습니다. 이미 활성화된 고급 Drive API와 `drive.file` 권한을 사용합니다.
4. 업데이트한 PC 앱의 **연결·설정 → 연결파일 불러오기**, 안드로이드의 **온라인 견적 요청함 → 연결파일 불러오기**에서 같은 파일을 선택합니다.

연결파일은 만료되지 않으며 두 사람이 함께 사용할 수 있습니다. 각 앱은 자체 기기 토큰을 자동 생성하므로 휴대폰 알림 등록이 다른 기기를 덮어쓰지 않습니다. 연결파일은 두 사용자 사이에서만 보관합니다. 고객 자료를 익명 공개하는 변경은 없습니다. 서버는 기존 등록 한도인 10개 기기를 유지합니다.

파일 생성 함수를 다시 실행해도 같은 연결정보가 들어 있는 파일이 생기며 기존 연결을 초기화하지 않습니다. 파일 생성이나 앱 업데이트는 운영 시트의 데이터를 변경하지 않습니다.

## 사용하는 방법

- **지금 동기화**를 누르면 구글 시트의 견적 요청을 로컬로 가져옵니다. 안드로이드는 기존 Room DB, PC는 기존 SQLite 보관함을 사용합니다. 내려받은 자료는 인터넷 없이 조회할 수 있습니다.
- 시트에서 삭제한 테스트 요청은 다음 전체 동기화 때 앱 목록에서도 없어집니다. 전체 페이지 수와 스냅샷 식별자가 일치해야 교체하므로, 연결이 끊기거나 중간에 시트가 바뀌면 기존 로컬 목록이 유지됩니다. 다시 동기화하면 됩니다.
- PC는 동기화 완료 때 보관함 옆의 `나무팜-견적요청.xlsx`를 갱신합니다. **로컬 엑셀 사본 열기**로 열 수 있습니다. 한 품목당 한 행이며 접수번호·성함·연락처·지역·묘목·규격·수량·요청사항·견적서 회신 정보를 담습니다. 전화번호는 앞자리 0을 유지합니다.
- 엑셀 사본은 조회용입니다. 그 파일을 편집해도 서버에 업로드되지 않습니다. 파일을 Excel에서 열어 둬 갱신하지 못하면 안내를 표시하며 앱의 동기화된 자료는 유지합니다. 파일을 닫고 다시 동기화하거나 사본 열기를 누르면 재생성됩니다.
- PC는 수동 동기화가 기본입니다. 필요하면 설정에서 60초 자동 동기화를 켤 수 있습니다. 안드로이드의 기존 푸시 알림은 유지됩니다.
- 로컬 초안, 판매 기록, 전송 대기는 요청함 갱신으로 삭제되지 않습니다. 앱의 ‘상담 종료·삭제’와 기존 보관기한 처리는 그대로 적용됩니다.

이전 서버에 연결된 앱은 기존 조회 방식을 유지합니다. 시트에서 지운 행까지 반영하려면 위 서버 업데이트가 필요합니다. 이전 연결코드 입력은 접힌 ‘이전 연결코드 방식’에 남겨 두었습니다. 기존 암호화 자료가 있는 경우에만 이전 자료 복원 기능을 사용합니다.

## 검증 범위

운영 홈페이지로 테스트 견적을 제출하지 않습니다. 서버의 가상 시트, PC의 임시 보관함, Android Room 테스트에서 연결파일 재사용, 페이지 누락·실패·변경, 빈 시트 반영, 기존 초안·전송 대기 보존을 확인합니다. 실제 Windows/Android 설치와 운영 서버 배포는 코드 커밋과 별도입니다.
