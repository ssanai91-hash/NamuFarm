# P0 읽기 전용 리뷰 기준

2026-11-17 작성. 최초 기준 main `f5f80d1468f0de635cd916c7ac6e2bc9406a4eb5`. 이후에는 **검토 시점의 main SHA와 비교 기준 SHA를 새로 고정**한다. 이 문서는 주문·입금·견적 만료·접수 제한의 데이터 손실/중복 처리 위험을 찾기 위한 수동 기준이다. 문서 작성이나 소스 검토를 실제 정상 동작 확인으로 간주하지 않는다.

## 범위와 사용법

- 작업 전 `AGENTS.md`, `NAMUFARM_PROJECT_STATUS.md`의 최신 결정과 관련 변경 파일만 읽는다. 변경 diff에서 아래 4영역과 이어지는 호출/저장 경로를 필요한 만큼 확인한다. 전체 저장소 조사를 매번 반복하지 않는다.
- 이후 수정마다 완료 보고에 4영역의 읽기 전용 자가 점검 결과를 붙인다. 문서만 바꾼 경우에도 실행 코드 diff가 없다는 근거로 영향 없음을 기록한다. 근거를 못 찾으면 미확인이다.
- 각 체크 항목은 **소스 기준 충족 / 우려 발견 / 미확인 / 영향 없음** 중 하나로 기록한다. 영향 없음에는 변경 범위와 이유가 필요하다. 체크 표시만으로 전수 검토/운영 안전을 보증하지 않는다.
- 코드의 구현 상태, 빌드/사용자 시험 상태, 운영 서버 배포 상태, 실제 기능 활성화 상태를 분리한다. 배포 버전 증거가 없으면 운영 미확인이다. 저장소 커밋으로 배포 완료를 추정하지 않는다.
- 리뷰 자체는 읽기 전용이다. 별도 수정 요청 전에는 발견한 문제를 고치거나 커밋하지 않는다. 임의 브랜치·PR·자동 리뷰 workflow·AI 서비스 연결을 만들지 않는다. 사용자 요청 없이 컴파일·자동시험·Actions·반복 CI 로그 분석·운영 API/시트 조회·쓰기·실제 주문/문자/메일 시험을 실행하지 않는다.
- 수정 작업은 사용자 승인 범위에서 main만 사용하고 `[skip ci]`로 커밋한다. 기존 URL·배포 ID·인증·패키지·DB·서명과 고객 원문/로컬 초안/전송 대기를 유지한다. 업무 데이터 변경은 기존 Apps Script API만 경유한다.
