# 나무팜 PC 디자인 기준

앱 버전은 0.4.9를 유지합니다. 버전은 사용자가 요청할 때만 올립니다.

## 공통 표현

- Windows 맑은 고딕 계열, 본문·표 16px / 큰 글씨 18px, 보조 문구 14px / 큰 글씨 16px, 화면·고객 제목 24px, 구역 제목 18px, 핵심 합계 28px.
- 버튼 높이는 공통 44px, 삭제·견적 버튼 최소 너비 140px. 연한 빨강 삭제와 연한 초록 견적 버튼을 유지합니다. 모서리는 버튼·입력 8px, 카드 12px입니다.
- 본문 배경 #F4F6F7, 카드·표 흰색, 기본 글자 #24313A, 보조 글자 #5C6B73, 사이드바 #193C32, 주요 작업 #2D6A4F를 사용합니다. 표의 줄무늬·머리글·경계는 중립색, 상태·선택은 작은 면적의 연한 색으로 표시합니다.
- 페이지 바깥 여백 24px, 카드 안쪽 12~16px, 관련 제어 간격 8px, 큰 정보 묶음 사이 12~16px를 기준으로 합니다. 정보량에 맞춰 유연하게 적용합니다.
- 메뉴 20px, 주요 작업 18px의 단색 선 아이콘을 사용합니다. SVG는 ui_icons.py의 원본 경로를 QtSvg로 로컬 렌더링하므로 외부 다운로드·아이콘 폰트가 필요하지 않습니다. 한글 라벨은 유지합니다.
- 현재 메뉴는 채움·왼쪽 강조선으로 표시하고, Tab·역방향 Tab·단축키로 들어간 키보드 포커스는 별도 선으로 표시합니다. 셀마다 포커스 네모를 다시 그리지 않습니다.

## 화면별 11개 보완

1. **견적요청**: 제목과 결과 건수를 상단 한 줄로 합칩니다. 고객명·접수번호 2단 구조를 유지하고 메일주소를 공식견적서 오른쪽에 표시합니다. 열별 최소 폭을 두며, 접수일은 MM.DD HH:mm로 표시하고 모델 값·툴팁에는 원래 전체 날짜·시간을 보존합니다.
2. **확정 견적**: 제목 중복을 없애고 전체·전달 대기·발송 완료 필터를 유지합니다. 상태 배지는 실제 글자 폭과 30px 높이를 기준으로 표시합니다. 서버 조회 / PC 보관 구분과 서버 조회 자료의 삭제 제한을 유지합니다.
3. **판매관리**: 제목·건수를 한 줄로 합치고 검색·상태 필터를 한 도구 줄에 모아 표의 세로 공간을 확보합니다. 고객명 아래 주문번호, 금액 오른쪽 정렬, 상태 필터, 다음 작업 안내를 유지합니다.
4. **배송·송장**: 주문 선택의 검색·필터를 한 줄에 정렬하고 전체 선택·선택 해제를 송장 준비 줄로 옮깁니다. 목록의 높이를 늘리고 하단 번호 반영 카드의 여백을 줄입니다. 로젠 XLS·CSV·번호 등록·출력 함수와 처리 순서는 유지합니다.
5. **매출·이익**: 기간·건수·수량·원가 미확인 건수에 필요한 최소 폭을 배정하고 금액 열에 여유 폭을 줍니다. 매출·세액·원가·비용·이익·건수·수량을 오른쪽 정렬합니다. 계산·기간·서버 응답 해석은 변경하지 않습니다.
6. **연결·설정**: 읽기 폭을 최대 920px로 제한하고 연결·최근 가져오기·변경사항을 항목명과 값으로 정렬합니다. 긴 엑셀 경로는 고급 설정으로 옮깁니다. 가져오기와 10분 자동 가져오기는 실제로 전송 대기도 반영한다는 설명을 툴팁에 둡니다. 마지막 성공은 이번 실행에서 성공한 실제 연결·동기화일 때만 표시합니다.
7. **견적 작업대**: 2026-10-20 선택한 2번 시안의 진녹색 머리글·연초록 고객 정보·좌우 30:70 구성을 사용합니다. 홈페이지 요청·`+ 견적`·`선택 요청 견적`은 같은 작업대를 엽니다. 품목 표는 일반 글씨 16px·40px 행, 큰 글씨 18px·48px 행으로 최대 8행을 한 화면에 표시하고, 이후 품목은 표 안에서 스크롤합니다. 묘목명·비고에 가변 폭을 우선 배정하고 단가 ± 입력칸은 작은 고정 폭으로 유지합니다. 빈 비고의 회색 기울임 `입력가능`은 delegate 표시만 사용하며 저장·PDF·문자·메일 데이터에는 포함하지 않습니다. 공식견적서 생성·미리보기와 96~104px 요청사항 입력칸을 왼쪽의 같은 테두리 안에 정렬합니다. 문자·메일은 20~22px 굵은 제목과 56~60px 버튼을 사용하며, 좁은 창에서는 제목을 18~20px로 조정합니다. 긴 고객 정보는 원문·복사·툴팁을 보존합니다. 작은 창은 각 영역의 스크롤로 모든 제어에 접근하며, 닫기는 고정 하단에 둡니다.
8. **견적 전달**: 고객명·견적번호는 헤더에서 한 번 표시하고 연락처·메일·공식견적서·수신방법만 요약에 둡니다. 합계는 본문의 한 곳에서 강조합니다. 표는 실제 품목 수에 맞추고 최대 네 행 이후 표 자체를 스크롤합니다. 요청사항·전달 안내는 펼쳐 볼 수 있습니다. 문자·메일·공식견적서와 현재 업무 단계 버튼은 기존 고정 하단에 유지합니다.
9. **고객·주문 상세**: 결제금액·주문번호를 중복 강조하지 않습니다. 고객·전화, 수령인·우편번호를 같은 행에 정렬하고 도로명·상세 주소를 넓게 둡니다. 배송 메모·수익 방식·연결 견적서는 펼쳐 볼 수 있으며 입력값과 견적서 출력 기능을 유지합니다. 원가·비용·원가 확인은 기본 화면에서 조작합니다. 판매 품목 표는 실제 행 수에 맞춥니다.
10. **큰 글씨**: 18px / 64px 행을 유지하며 요청 표의 열별 최소 폭을 재배정합니다. 읽기 전용 견적 입력칸도 큰 글씨에 맞춰 높입니다. 날짜는 간결한 표시와 전체 값 툴팁을 사용합니다. 폭이 최소 합계보다 작을 때는 데이터 열을 숨기거나 글자를 줄이는 대신 표의 가로 스크롤을 허용합니다.
11. **빈 목록**: 요청 없음·검색 결과 없음·상태 조건에 맞는 자료 없음·집계 조회 전 상태를 짧은 문장으로 구분합니다. 안내는 표의 별도 행이 아닌 마우스 입력을 가로채지 않는 뷰포트 레이블이므로 선택·정렬·업무 자료 매핑에 영향을 주지 않습니다.

## 업무·저장 규칙

견적요청을 시작 화면으로 사용하며 여섯 메뉴를 유지합니다. 전화 견적, 임시저장 UI, 상세 보기, 중복 상단 검색·하단 요약은 다시 추가하지 않습니다. F5 가져오기와 목록 Enter 열기, 10분 자동 가져오기, 입력 중 새로고침 방지를 유지합니다.

구매확정=입금확인, 견적확정·견적발송완료·입금확인·배송완료의 기존 처리 조건, 삭제 확인, 서버 확인 전 전송 대기 보존, 암호화 보관·기기 연결·서버 코드·자료 형식은 변경하지 않습니다. 단순 표시 날짜와 아이콘은 모델 값에 저장하지 않습니다. 접힌 입력도 collect 함수에서 원래처럼 수집합니다.

## 검증 범위

격리한 Linux Qt offscreen / Fusion / PySide6 6.12 환경에서 가상 자료와 대체 한글 글꼴로 FHD·1366×768, 팝업 1160×760·1100×660, 큰 글씨·빈 목록·20품목을 확인했습니다. 네트워크를 차단하고 실제 보관함을 열지 않았습니다. 메뉴 이동, 필터, 삭제 활성화·서버 조회 삭제 제한, 전체 날짜 보존, 가격·배송비 계산, 접힌 고객 입력값 수집, 키보드 포커스, 빈 목록, 10분 타이머를 점검했습니다.

Windows 실제 맑은 고딕·100/125/150% 배율, 실제 서버 가져오기·삭제·문자·메일·공식견적서·입금·배송 저장·통계 정확도·패키지 빌드는 사용자 로컬 검증 대상입니다. 이번 변경은 Windows 배포나 서버 호출을 수행하지 않습니다.
