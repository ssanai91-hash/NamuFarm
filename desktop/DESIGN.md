# 나피 PC 공통 디자인

- 기본 본문·표 16px, 보조 문구 14px, 제목·합계 28px. 연결·설정의 ‘큰 글씨로 보기’는 본문을 18px로 바꾸며 PC 화면 설정으로 기억합니다.
- 기본 버튼 44px, 주요 작업 48px 수준의 패딩·높이를 사용합니다. 버튼·입력 모서리는 8px, 카드 12px이며 숫자·금액은 오른쪽으로 정렬합니다.
- 정상 상태는 상단 안내 버튼에 모으고 오류·처리 중·전송 대기는 별도 안내를 펼칩니다. 안내 버튼 또는 ‘자세히 보기’에서 원래 문구를 확인합니다. 마지막 동기화 성공 시각은 이번 실행 중 성공한 연결·동기화에만 갱신됩니다.
- 견적요청·견적확정·판매관리 표는 화면 폭에 맞춰 핵심 열을 표시합니다. 원래 논리 열 번호와 자료는 유지되며 상세 정보는 ‘요청 상세’, ‘선택 견적 열기’, ‘고객 관리 열기’에서 확인할 수 있습니다. 긴 셀 내용은 툴팁으로도 볼 수 있습니다.
- 연결·설정은 서버 연결 상태 / 화면과 로컬 자료 / 접힌 고급 설정으로 나눴습니다. 서버 주소는 고급 설정에서 읽기 전용으로 확인합니다.
- 긴 팝업은 본문만 스크롤하고 헤더와 마지막 작업 버튼은 남겨 둡니다. 요청 견적 편집 표는 표시 순서만 수량 → 단가 → 금액으로 바꿨습니다.
- Tab 키 포커스를 표시하고, 목록에서 Enter로 상세 화면을 엽니다. F5 동기화, Ctrl+K 검색, Ctrl+N 전화 견적 단축키를 유지합니다.

## 상용 업무 화면 보완 10개

1. **오늘의 업무**: 큰 홍보 영역과 고정 도움말을 제거하고 새 요청·전달 대기·출고 대기 요약을 해당 목록에 연결합니다. 업무 목록에서 요청 작성·견적 전달·판매 상세로 이동하며 월 매출은 하단 보조 정보로 표시합니다.
2. **견적요청**: 고객명을 첫 열에, 접수번호를 같은 셀의 보조 줄에 표시합니다. 표 제목에 검색 결과 건수를 표시하고 요청 상세·삭제·견적 작성을 함께 배치합니다. 숨겨진 원본 열과 상세 정보는 유지합니다.
3. **확정 견적**: 전체·전달 대기·발송 완료 필터에 건수를 표시합니다. 상태 배지와 자료 위치(서버 조회 / PC 보관)를 구분하며 서버 조회 자료의 삭제 제한 이유를 선택 안내와 툴팁에 표시합니다. 고객/견적번호 열 제목을 누르면 기존 견적번호 정렬을 바꿉니다.
4. **판매관리**: 전체·입금확인·배송완료·구매취소 필터와 건수, 선택 주문의 다음 작업을 표시합니다. 고객명 아래 주문번호를 표시하고 입금확인·배송완료 등 기존 상태를 배지로 표현합니다.
5. **배송·송장**: 주문 선택 → 로젠 XLS 송장 준비 → 송장번호 반영·확인으로 제어를 묶습니다. 선택 건수와 후속 안내를 표시하며 기존 XLS/CSV 가져오기·운송장 처리 방식은 유지합니다.
6. **연결·설정**: 읽기 영역을 최대 1040px로 제한하고 연결 정보·이번 실행의 마지막 동기화 성공·전송 대기 건수를 모읍니다. 고급 설정은 접힌 상태와 읽기 전용 서버 주소를 유지합니다.
7. **견적 작업대**: 고객 정보는 입력칸 대신 선택·복사 가능한 요약으로 표시합니다. 요청 설명 문장과 ‘홈페이지 요청 · 신규’ 헤더, 임시저장 버튼·편집 결과의 임시저장 분기·전용 콜백을 제거합니다. 단가 ±는 44px 클릭 영역을 유지하며 상하 패딩을 줄이고 편집 행에 여유를 둡니다.
8. **견적 전달**: 고객명 → 견적번호 → 상태·합계의 헤더로 바꾸고 고객 전달 수단과 업무 단계 버튼을 다른 줄에 묶습니다. 배송비 편집 시 헤더 합계도 함께 갱신합니다.
9. **고객 관리 상세**: 견적 전달과 같은 고객 중심 헤더, 관련 견적번호와 출력 가능 여부, 수정 후 저장이 필요한 상태를 표시합니다. 구매취소·입금확인·배송완료 처리 조건은 유지합니다.
10. **작은 화면과 공통 표현**: 메뉴 번호를 없애고 견적·주문 / 운영으로 묶으며 아이콘과 한글 명칭을 함께 표시합니다. 선택 메뉴와 키보드 포커스를 다른 표현으로 구분합니다. 표 머리글은 밝은 중립색으로 바꾸고 대시보드·배송 페이지의 바깥 스크롤을 없애 표 스크롤에 공간을 배분합니다. 상단 검색 범위는 실제 동작에 맞게 ‘주문 검색’으로 표시합니다.

임시저장 UI 제거는 견적 확정·수기 견적 등록·배송비·발송 상태·전송 대기에 필요한 내부 저장 기능과 기존 보관 자료를 삭제하지 않습니다. 서버 동기화와 데이터 형식·업무 상태는 그대로 사용합니다.

## 사용자 확인

이 변경의 컴파일·실행 검증은 사용자 수행 대상입니다. Windows 100%·125%·150% 배율, 큰 글씨, 긴 묘목명·주소·다품목, Tab 이동과 Enter 열기, 실제 동기화 성공·실패 안내를 확인해주세요.

서버 인증·데이터 저장·견적발송·입금확인·배송완료 처리 규칙은 변경하지 않습니다.
